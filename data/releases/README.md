# data/releases/

One CSV per release month, named `YYYY-MM.csv`.

A release is computed once when the month closes and is never recomputed. That is
the whole point of this directory: a figure cited from `releases/2026-07.csv`
reads the same whenever someone follows the citation, which a live number cannot
promise.

Empty until the first release is published. See [../README.md](../README.md).
