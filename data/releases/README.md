# data/releases/

One CSV per release month, named `YYYY-MM.csv`.

A release is computed once when the month closes. That is the whole point of this
directory: a figure cited from `releases/2026-07.csv` reads the same whenever
someone follows the citation, which a live number cannot promise.

The one exception is a correction published at the source, which luvs.one records
in its own changelog. When that happens the file here follows, as its own commit,
so the mirror never contradicts the source and nothing changes without a trace.

See [../README.md](../README.md).
